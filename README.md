# Global Currency

Proyecto institucional del Colegio Bilingüe Los Ángeles.

**Realizado por: Elvin Chen**

Global Currency es una página web estática para consultar monedas internacionales, realizar conversiones simuladas y visualizar tendencias financieras con fines educativos.

## Tecnologías utilizadas

- HTML
- CSS
- JavaScript

## Funciones principales

- Consulta y filtrado de monedas internacionales.
- Conversor de divisas, incluido Bitcoin.
- Tendencias y rankings simulados.
- Oscilaciones de precios con fines educativos.
- Consejos para empresas.
- Diseño responsive.

## Publicación con GitHub Pages

El proyecto no requiere instalación ni servidor de desarrollo. Tras subir la rama principal a GitHub, activa **Settings → Pages → Deploy from a branch**, elige la rama publicada y la carpeta **/(root)**.

> Los valores mostrados son simulados para fines académicos y no deben usarse para decisiones financieras reales.
